布局决策

  1. 登录拆两栏:左品牌右表单,一次登录只放一个焦点;品牌区承担入口的「公司感」,表单区保持极简(为什么:登录页信息越少,输错率越低)。
  2. 四态反馈:校验失败红字 → 登录中禁用按钮 → 成功绿色提示,三态都经 render() 重绘(为什么:后台并发高,状态不清容易反复提交)。
  3. 宽度 1000px:在 1920×1080 / 1440×900 下都留出呼吸空间,不做全屏铺满(为什么:登录是低频操作,窄卡更聚焦)。
  4. 配色为演示令牌:整套演示稿统一「星云工作台」令牌,接入真实项目时替换 :root B 段(待确认)。
